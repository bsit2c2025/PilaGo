PilaGo is a digital tricycle queue management system designed to make the traditional pila system in the Philippines more organized, transparent, and efficient. It helps passengers, tricycle drivers, and terminal administrators coordinate queues and track whose turn is next.
By digitizing the queueing process, Sunod Sakay aims to promote fairness, reduce confusion, and ensure that drivers are dispatched in the proper order. It provides a more convenient way to manage tricycle terminals while preserving the familiar Filipino culture of lining up and taking turns.
Built with local communities in mind, Sunod Sakay envisions a modern transportation experience where every driver gets a fair opportunity, every passenger understands the queue, and every ride begins with an orderly system.
